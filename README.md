# Machine Learning Projects
A repository showcasing personal machine learning projects, with an emphasis on practical tooling and reusable components.

- The repository includes an __AWS__ folder that explores key cloud functionalities such as S3 access patterns, boto3 wrappers, state machine orchestration, AWS Batch workflows, and Lambda packaging strategies—both zipped and containerized via Docker and ECR, among other services. These modules are designed as boilerplate code for rapid reuse, not full end-to-end pipelines, offering a foundation for scalable experimentation and deployment.
