

\## Additional Notes

* When making a lambda from using a zip file, control click on the two files, then zip those, DO NOT zip the folder the files are in. That will error because lambda expects
  the files to be in the root zipped folder, but zipping a folder with files injects an new folder for some reason. The correct zipped output
  will be a zip file named after one of the project files.
